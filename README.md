# DocuLens

An intelligent document analysis and extraction system.

## Project Structure

```
DocuLens/
│
├── frontend/     # Frontend client application
├── backend/      # Backend API and services
├── docs/         # Documentation and project guides
├── test_data/    # Sample documents and test datasets
└── README.md     # Project overview
```

## Getting Started

### Prerequisites
- Refer to individual directory READMEs for specific frontend and backend setup instructions.

### Directories
- **`frontend/`**: Contains the client-side user interface.
- **`backend/`**: Contains API routes, document processing logic, and OCR/ML services.
- **`docs/`**: Technical specs, architecture diagrams, and usage documentation.
- **`test_data/`**: Test files, sample inputs, and validation data.
